## English

**Summary: Exit Rush does not collect, transmit, sell, or share any personal data.**

1. **What we collect.** Nothing. The game has no accounts, no sign-in, no advertising, no analytics, and no tracking.
2. **What stays on your device.** Your game progress and settings (levels cleared, skill points, language, graphics quality,
   volume) are saved **only on your device** (app storage / browser local storage). We can't access this data.
3. **Network.** The iOS app runs fully offline and makes no network requests during play. The web version is served by GitHub Pages,
   which, like any web host, may log technical request data such as IP addresses. See GitHub's privacy statement:
   <https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement>.
4. **Children.** The game doesn't knowingly collect personal information from anyone, including children under 13.
5. **Deleting your data.** Delete the app (iOS) or clear site data for the page (web). This removes all saved progress.
6. **Tracking.** We don't track you across apps or websites, and the app doesn't use the advertising identifier (IDFA).
7. **Changes.** If a future version adds features that collect data (for example ads or purchases), we'll update this policy and
   the App Store privacy details before that version is released, and show the new effective date above.
8. **Contact.** Questions: [email address].

*Hong City Rail / 香城鐵路 is fictional. This game is a parody and is not affiliated with any real railway operator.*
